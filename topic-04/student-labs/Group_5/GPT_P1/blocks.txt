@startuml

skinparam classAttributeIconSize 0
skinparam shadowing false

class "Клиент" as Client {
  +ФИО: String
  +почта: String
}

class "Камера" as Camera {
  +серийныйНомер: String
  +модель: String
}

class "Бронь" as Booking {
  +начало: DateTime
  +конец: DateTime
  +статус: СтатусБрони
}

enum "СтатусБрони" as BookingStatus {
  Подтверждена
  Отменена
}

Client "1" -- "0..*" Booking : владеет
Camera "1" -- "0..*" Booking : относится к

Booking ..> BookingStatus : использует

note bottom of Booking
  Ограничения:

  1. начало < конец

  2. Интервалы A и B пересекаются,
     если:
     A.начало < B.конец
     и
     B.начало < A.конец

  3. Новая бронь создаётся
     только при отсутствии пересечения
     с подтверждённой бронью
     той же камеры.

  4. Новая бронь имеет статус
     Подтверждена.

  5. Отменённая бронь сохраняется,
     но не блокирует интервал.

  6. Отказ в заявке
     не создаёт объект Бронь.
end note

@enduml

@startuml

skinparam shadowing false
autonumber

actor "Клиент" as Client

box "Граница системы"
  participant "Система бронирования" as System
end box

Client -> System : Подать заявку(камера, начало, конец)
activate System

System -> System : Проверить начало < конец

alt начало >= конец

    System --> Client : Некорректный интервал
    note right of System
      Бронь не создаётся.
    end note

else начало < конец

    System -> System : Проверить подтверждённые брони\nтой же камеры

    note right of System
      Пересечение с существующей
      бронью B есть, если:

      начало < B.конец
      и
      B.начало < конец

      Учитываются только брони
      со статусом Подтверждена.
    end note

    alt Есть пересечение

        System --> Client : Отказ с причиной:\nинтервал пересекается с бронью

        note right of System
          Объект Бронь
          не создаётся.
        end note

    else Нет пересечения

        System -> System : Создать бронь\n(камера, клиент, начало, конец)

        System -> System : Установить статус = Подтверждена

        System --> Client : Бронь подтверждена

    end

end

deactivate System

@enduml


@startuml

skinparam shadowing false

state "Подтверждена" as Confirmed
state "Отменена" as Cancelled

[*] --> Confirmed : Создать бронь\n[начало < конец\nи нет пересечения]

Confirmed --> Cancelled : Отменить\n[клиент — владелец брони]\n/ сохранить запись

note right of Confirmed
  Бронь блокирует интервал
  своей камеры.

  Отменить бронь может
  только её владелец.
end note

note right of Cancelled
  Запись сохраняется.
  Интервал не блокируется.
end note

note bottom of Confirmed
  При пересечении с подтверждённой
  бронью той же камеры
  новая бронь не создаётся.

  Некорректный интервал также
  не приводит к созданию брони.

  Отказ не является
  состоянием объекта Бронь.
end note

@enduml
