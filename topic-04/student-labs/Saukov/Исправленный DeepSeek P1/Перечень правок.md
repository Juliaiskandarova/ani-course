# Исправленный комплект DeepSeek P1

Взяли за основу DeepSeek P1. Все четыре исходные диаграммы построились, ключевые правила бронирования уже были отражены. Правки согласуют проверку интервала и условия создания брони во всех представлениях.

| Диаграмма | Что исправлено | Требования |
|---|---|---|
| Вариантов использования | Создание показано только для корректного свободного интервала. Отказ предусмотрен как для некорректного интервала, так и для конфликта. Проверка занятости уточнена в примечании к заявке. | R2, R7 |
| Классов | В примечании к брони указаны оба условия создания и ограничение проверки подтверждёнными бронями той же камеры. Кратности сохранены. | R2, R6, R7 |
| Последовательности | Вместо одного предусловия показана проверка `начало < конец` и отдельная ветка отказа с причиной. Поиск конфликтов выполняется только после успешной валидации. Создание остаётся только в ветке успеха. | R2, R7 |
| Состояний | У начального перехода указаны оба условия создания. Убрана конечная вершина после отмены, чтобы явно показать сохранение записи в статусе «Отменена». Условие владельца и освобождение интервала сохранены. | R2, R3, R7, R8 |

После правок четыре сценария дают соответственно отказ без создания брони, подтверждение на стыке, подтверждение для другой камеры и подтверждение после отмены. Если начало совпадает с концом или позже него, заявка отклоняется с причиной до поиска конфликтов.
