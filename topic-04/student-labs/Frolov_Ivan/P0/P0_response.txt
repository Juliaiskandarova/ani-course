**Диаграмма прецедентов**

```plantuml
@startuml
left to right direction

actor "Клиент" as client
actor "Сотрудник проката" as staff

rectangle "Бронирование камер" {
  usecase "Подать заявку на бронь" as UC_Submit
  usecase "Просмотреть свои брони" as UC_My
  usecase "Отменить свою подтверждённую бронь" as UC_Cancel
  usecase "Просмотреть все брони" as UC_All
}

client --> UC_Submit
client --> UC_My
client --> UC_Cancel
staff --> UC_All

note right of UC_Submit
  Заявка: камера, начало и конец интервала.
  Если подтверждённая бронь той же камеры
  пересекает интервал — отказ с причиной.
  Иначе создаётся бронь «Подтверждена».
end note

note right of UC_Cancel
  Только своя бронь в статусе «Подтверждена».
  Запись сохраняется.
  Отменённая бронь не блокирует интервал.
end note
@enduml
```

**Диаграмма классов**

```plantuml
@startuml
hide circle
skinparam classAttributeIconSize 0

class Камера {
  серийныйНомер
  модель
}

class Клиент {
  ФИО
  почта
}

class Бронь {
  начало
  конец
  статус : СтатусБрони
}

enum СтатусБрони {
  Подтверждена
  Отменена
}

Камера "1" -- "0..*" Бронь
Клиент "1" -- "0..*" Бронь
Бронь --> СтатусБрони

note bottom of Бронь
  Интервал корректен, если начало раньше конца.
  Соседние интервалы могут соприкасаться.
  Интервал блокирует только бронь «Подтверждена».
end note
@enduml
```

**Диаграмма последовательности: заявка на бронь**

```plantuml
@startuml
actor "Клиент" as client
participant "Система" as system

client -> system : Подать заявку(камера, начало, конец)
system -> system : Проверить: начало раньше конца

alt Начало не раньше конца
  system --> client : Отказ(причина: некорректный интервал)
else Интервал корректен
  system -> system : Найти подтверждённые брони той же камеры,\nпересекающие интервал\n(соприкосновение допустимо)
  alt Пересечение есть
    system --> client : Отказ(причина: интервал занят)
  else Пересечений нет
    create participant "Бронь" as booking
    system -> booking : Создать(камера, клиент, начало, конец,\nстатус = Подтверждена)
    system --> client : Бронь подтверждена
  end
end
@enduml
```

**Диаграмма состояний брони**

```plantuml
@startuml
[*] --> Подтверждена : заявка принята,\nбронь создана

Подтверждена --> Отменена : клиент отменяет\nсвою бронь

note right of Отменена
  Запись сохраняется.
  Отменённая бронь не блокирует интервал.
end note

note left of Подтверждена
  При отказе в заявке бронь не создаётся.
  Отдельного статуса отказа нет.
end note
@enduml
```
