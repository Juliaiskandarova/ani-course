По приведённому ниже заданию спроектируй реляционную схему базы данных.

Выдай один полный блок DBML для вставки в https://dbdiagram.io/.
Нужна только схема: таблицы, поля, типы данных, первичные и внешние ключи, связи.
Все операции и отчёты из условия должны быть реализуемы на её основе.
SQL-запросы и код приложения не нужны.
Если необходимы допущения, явно укажи их в комментариях DBML.

Полное условие задания:

13. Тестирование студентов

Есть перечень специальностей и списки предметов по каждой специальности (одни и те же предметы могут быть на разных специальностях). Есть списки тем по каждому предмету и вопросов по каждой теме (некоторые вопросы могут относиться к разным темам/предметам). Есть списки групп студентов по каждой специальности.

Требуется:
- Поддержка генерации набора тестов для студентов выбранной группы по заданной теме/темам с возможностью сделать одинаковый набор вопросов для всех или уникальные наборы вопросов для каждого студента группы;
- Поддержка внесения результатов тестирования с автом. оценкой (неправ.ответ: -1 балл; неполный: -0,5; просрочка по времени со сдачей теста: -0,5);
- Поддержка архива результатов тестирования студентов;
- Поддержка внесения/изменения/удаления предметов, тем и вопросов тестирования;

Отчеты:
- Результаты конкр. теста для группы;
- Результаты тестирования группы/групп за период; список двоечников;
- Самые сложные вопросы.
