Театральная касса

Есть список театров. Для каждого театра есть репертуар. Один и тот же спектакль может быть поставлен в разных театрах. Места в зрительном зале разделены минимум на 2 категории (по цене); есть информация об общем количестве мест каждой категории. На каждую постановку в каждом театре есть цены на билет (с учетом категорий мест). При покупке билетов на две и более постановок, человек получает скидку 10%, начиная со второй постановки. При покупке более 10 билетов на одну постановку, также есть скидка на все эти билеты 10%. Скидки суммируются.
Требуется:
- Поиск театра и периода постановки по названию;
- Поддержка продажи билетов на одну и несколько постановок;
- Поддержка возврата билетов с удержанием 50% заплаченного, если возврат происходит накануне спектакля (при частичном возврате билетов после их «оптовой» покупки в случае необходимости (если купленных билетов осталось <10) должен быть произведен перерасчет);
Отчеты:
- Репертуар театров города;
- Текущее состояние по проданным билетам на постановки выбранного театра;
- Финансовый отчет за квартал/год по всем театрам;
- Коэффициент «пустых» продаж (отношение количества возвращенных билетов к проданным);
- Коэффициент «успешности» (отношение количества реально проданных билетом к общему количеству мест (с учетом категорий мест)) по каждому театру и по каждой постановке за выбранный период времени.
