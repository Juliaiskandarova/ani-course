Целью статьи является исследование наиболее популярных форматов хранения текстовых данных (CSV, JSON, XML) для последующего анализа методами машинного обучения на примере выгруженных чатов видеоконференций платформы Zoom. Сравнение проводилось по критериям размера файла, скорости парсинга, поддержки библиотеками Python и человекочитаемости. Установлено, что для одинаковых данных файлы CSV, JSON и XML занимают 81, 203 и 455 байт соответственно, а среднее время операции над данными составляет 45, 461,5 и 617 мс. Сделан вывод о целесообразности использования формата CSV для хранения текстовых данных из чата Zoom.
