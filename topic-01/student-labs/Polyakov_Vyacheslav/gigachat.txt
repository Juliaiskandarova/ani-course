Целью исследования является сравнительный анализ форматов CSV, JSON и XML для хранения текстовых данных из чатов видеоконференций Zoom с целью их последующей обработки методами машинного обучения. Оценка проводилась по критериям размера файла, скорости сериализации-десериализации, поддержки библиотеками Python и человекочитаемости на основе работ различных авторов. Результаты показали, что для одинаковых данных формат CSV занимает наименьший объем (81 байт против 203 байт у JSON и 455 байт у XML) и обеспечивает минимальное среднее время операции над данными (45 мс против 461,5 мс и 617 мс соответственно). Все три формата поддерживаются языком Python, однако человекочитаемость оценена выше у CSV (5 баллов). Исследование скорости с использованием FastJSON и Microsoft XML Parser выявило преимущество JSON в десериализации (644 мс против 773 мс), но XML эффективнее при работе со сложными структурами. На примере добавления 10 000 записей CSV показал время 4,6 секунды. Сделан вывод о целесообразности использования формата CSV для хранения неструктурированных данных чатов Zoom ввиду их плоской структуры, обеспечивающей минимальные потери объема памяти и высокую эффективность обработки. Работа может быть дополнена внедрением новых критериев оценки.
