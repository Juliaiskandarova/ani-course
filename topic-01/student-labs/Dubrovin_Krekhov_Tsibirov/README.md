# ЛР1. Генерация аннотаций к научным статьям с помощью LLM

Группа 5040102/60201: Дубровин Т. Г., Крехов Д. А., Цибиров М. А.

Отчёт — [`report.pdf`](report.pdf).

## Что сделано

Две статьи по теме автоматического реферирования (русская и английская), из них удалены авторские аннотации и ключевые слова. Аннотации сгенерированы тремя моделями разных производителей (по одной на участника) двумя промптами. Результат сравнён с авторскими аннотациями по ROUGE-1/ROUGE-L, каждое утверждение проверено по тексту статьи вручную.

| Участник | Модель |
|---|---|
| Дубровин Т. Г. | Claude Opus 5.5 (+ доп. эксперимент: Claude Haiku 5.5, Claude Sonnet 5.5) |
| Крехов Д. А. | ChatGPT (chatgpt.com, модель по умолчанию, Think выкл.) |
| Цибиров М. А. | DeepSeek (chat.deepseek.com, Deep thinking и Smart Search выкл.) |

Статьи:
1. RU — Голубинский А.Н., Толстых А.А., Толстых М.Ю. Автоматическая генерация аннотаций научных статей на основе больших языковых моделей // Информатика и автоматизация. 2025. Т. 24, № 1. С. 275–301. DOI: [10.15622/ia.24.1.10](https://doi.org/10.15622/ia.24.1.10)
2. EN — Jaaouine I., King R.D. Mitigating Hallucinations in Zero-Shot Scientific Summarisation: A Pilot Study. [arXiv:2512.00931](https://arxiv.org/abs/2512.00931), 2025

Промпты: `v1` — строгий (структура, объём, запрет добавлять факты, самопроверка; по шаблону со слайда 14), `v0` — простой («Напиши аннотацию к этой научной статье»).

## Основные результаты (промпт v1)

| Модель | RU ROUGE-1 / ROUGE-L, % | EN ROUGE-1 / ROUGE-L, % | Галлюцинации |
|---|---|---|---|
| DeepSeek | 28.8 / 14.6 | 52.3 / 28.6 | 0 |
| ChatGPT | 29.7 / 11.2 | 60.1 / 34.8 | 0 |
| Claude Opus 5.5 | 26.9 / 12.9 | 59.0 / 32.7 | 0 |

- Со строгим промптом галлюцинаций нет ни у одной модели. С простым промптом Claude Opus и Claude Sonnet дописали в английскую аннотацию собственный вывод, которого нет в статье.
- ROUGE для русской статьи низкий у всех, потому что авторская аннотация описательная и без чисел. Аннотация с галлюцинацией может иметь ROUGE выше, чем аннотации без ошибок.
- Лучшая модель — ChatGPT: ноль ошибок по фактам и наибольший ROUGE-1. Подробности, все таблицы и выводы — в отчёте.

## Структура папки

```
report.pdf                  отчёт
articles/
  ru_article.txt            текст статьи без аннотации и ключевых слов (то, что получали модели)
  ru_reference_abstract.txt авторская аннотация — эталон
  ru_keywords.txt           удалённые ключевые слова
  en_*                      то же для английской статьи
prompts/
  prompt_v1_{ru,en}.txt     строгий промпт ({ARTICLE} — место вставки текста статьи)
  prompt_v0_{ru,en}.txt     простой промпт
answers/
  v1/, v0/                  аннотации: {ru,en}_{deepseek,chatgpt,opus,sonnet,haiku}.txt
  raw/                      ответы DeepSeek и ChatGPT как есть, до удаления вводных фраз, заголовков и ключевых слов
factcheck.md                протокол ручной проверки фактов
tools/
  prepare_texts.py          подготовка текста статьи и эталона из PDF
  rouge.py                  ROUGE-1 / ROUGE-L (F1), работает с кириллицей
```

Пересчёт ROUGE: `python tools/rouge.py articles/en_reference_abstract.txt answers/v1/en_*.txt`
