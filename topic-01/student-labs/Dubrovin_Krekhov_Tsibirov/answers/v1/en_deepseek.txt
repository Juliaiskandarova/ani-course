This pilot study aimed to investigate whether prompt engineering methods can mitigate context inconsistency hallucinations in zero-shot scientific summarisation, measured by proxy through the lexical and semantic alignment between LLM-generated summaries and reference text. Eight open-access yeast biotechnology paper abstracts were summarised by six instruction-tuned LLMs under seven prompt conditions (baseline, PE-1, PE-2, CR-K1, CR-K2, RA-K1, RA-K2), yielding 336 LLM-generated summaries; evaluation used ROUGE-1, ROUGE-2, ROUGE-L, BERTScore, cosine similarity, and METEOR Score, with significance tested via Wilcoxon signed-rank tests with Bonferroni-Holm correction and bias-corrected and accelerated (BCa) bootstrap 95% confidence intervals, considering only combinations significant across both tests. The results showed that context repetition (CR-K1 and CR-K2) significantly improved lexical alignment with the abstract, supporting H1, and random addition (RA-K1 and RA-K2) achieved the highest improvement in lexical alignment, supporting H2; increased instruction complexity did not significantly improve alignment, with PE-1 causing a decline in semantic alignment across BERTScore, cosine similarity, and METEOR score, so H3 was not supported; and H4 was partially supported, as CR-K2 significantly improved lexical alignment with repeated key sentences only across ROUGE-2 for K = 2. It is concluded that prompt method can have a significant effect on lexical and semantic alignment in zero-shot scientific summarisation, and that prompt engineering presents a practical tool for reducing context inconsistency hallucinations within LLM-based scientific summarisation.
