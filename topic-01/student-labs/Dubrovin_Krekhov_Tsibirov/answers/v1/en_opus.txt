The study investigates whether prompt methods can mitigate context inconsistency hallucinations in zero-shot large language model (LLM) summarisation of yeast biotechnology abstracts. Seven prompt methods were evaluated: a simple baseline prompt, two prompts of increasing instruction complexity (PE-1 and PE-2), context repetition of key sentences (CR-K1, CR-K2) and random addition of abstract sentences (RA-K1, RA-K2). Abstracts of eight open-access papers were summarised by six instruction-tuned LLMs via the Hugging Face Inference API, yielding 336 summaries. Lexical and semantic alignment with the abstract and with repeated key sentences was measured using ROUGE-1, ROUGE-2, ROUGE-L, BERTScore, METEOR score and cosine similarity, giving 3744 evaluation metrics. Paired differences from the baseline were tested with the Wilcoxon signed-rank test with Bonferroni-Holm correction and the bias-corrected and accelerated (BCa) bootstrap method with 10000 replicates. Context repetition significantly improved lexical alignment with the abstract across ROUGE-1, ROUGE-2 and ROUGE-L for K = 1,2. Random addition significantly improved lexical and semantic alignment with both the abstract and the key sentences and achieved the highest improvement in lexical alignment. PE-1 significantly reduced semantic alignment across BERTScore, cosine similarity and METEOR score, while PE-2 effects were not significant. Context repetition improved alignment with repeated key sentences only across ROUGE-2 for K = 2. It is concluded that prompt methods can significantly affect lexical and semantic alignment in zero-shot scientific summarisation and that prompt engineering is a practical tool for reducing context inconsistency hallucinations.
