LEAST-SQUARES APPROXIMATION
Abstract: In engineering research, the task of approximation — constructing a function from discrete values — often arises. These discrete values can be obtained from an experiment, from observations of a certain quantity, or from certain calculations (for example, when solving a differential equation by numerical methods, a table of correspondence between variable values and approximate solution values is obtained). Knowledge of the basic methods and formulas for constructing approximating functions is professionally significant for students of a technical university; therefore, in this work, we considered the basic ideas of approximation.
Keywords: approximation, smoothing, least-squares approximation, empirical formula.
To obtain a unique solution to the approximation problem, it is necessary to: 1) define the general form of the approximating function, including unknown coefficients, 2) find the parameter values based on a given closeness criterion. There are two main approaches to defining closeness — interpolation and smoothing.
Interpolation is constructed using an interpolation polynomial of the n-th degree, which passes directly through all points of a given data set. In this case, the approximating function is represented as an interpolation polynomial in the Lagrange form or an interpolation polynomial in the Newton form.
Smoothing is performed by constructing an approximating function that passes close to the points from a given data array. Thus, the approximating function smooths all random noise (or errors). The approximating function obtained by smoothing is called an empirical formula.
The least squares method is a mathematical method based on determining an approximating function constructed in the closest proximity to the points of a given set of experimental data. The closeness of the original and approximating functions is determined by a numerical measure, namely: the sum of the squares of the deviations of the experimental data from the approximating curve must be minimal.
The degree of approximation accuracy can be estimated by the value of the mean square deviation. The approximating function is also evaluated by the mean approximation error — the average deviation of the calculated values from the actual ones. The acceptable limit is A < 10%.
