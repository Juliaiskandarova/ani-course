# Лабораторная работа: научный перевод

Статья: В. А. Есаулов, «Метод сверточного градиентного спуска», 2025, DOI: 10.17213/1560-3644-2025-3-33-39.
Источник: https://cyberleninka.ru/article/n/metod-svertochnogo-gradientnogo-spuska

**Важное ограничение.** Варианты V1, V2, V3 являются *демонстрационными редакторскими вариантами*, а не результатами независимых запусков трёх разных языковых моделей. Доказать относительное качество реальных моделей по ним нельзя. Для полноценного эксперимента нужны 6 запусков в 6 новых чатах соответствующих систем.

Часть А — перефразированная авторская аннотация, а часть Б — авторское учебное изложение по мотивам основного текста статьи (224 слов). Они не являются дословной выдержкой. Авторский английский эталон существует в первоисточнике, но в наборе хранится ссылка, а не полный текст.

Метрики `metrics.csv` являются воспроизводимым локальным расчётом для демонстрационных вариантов. BLEU-4: lowercase, split по пробелам, пунктуация сохраняется, smoothing=none, как в MetricGate по умолчанию. Cosine: локальная smoothed TF-IDF (scikit-learn) на паре документов; она может не совпасть с результатом MetricGate, который описывает IDF без сглаживания.

После реальных запусков замените файлы `translations/V*.txt`, допишите реальные названия моделей и версии, скопируйте оригинал английской части А в `reference_A_en.txt`, запустите `python recalculate.py` и обновите таблицу оценок терминов и вывод.

Для загрузки переименуйте `Surname_Name` в Фамилия_Имя латиницей и загрузите в `topic-02/student-labs/`.
