PART A
Title: Method of Convolutional Gradient Descent
Abstract: This study investigates a way to improve gradient descent by processing gradient values with a sliding convolution filter. The technique is intended for objective functions with complex landscapes. It offers a neural network interpretation of the computational process. Numerical tests reported in the article show that the algorithm can achieve accurate results efficiently.
Keywords: global optimization, objective function, gradient method, nonlinear function, neural network, algorithm.

PART B
Gradient descent is a numerical optimization technique for finding the minimum of an objective function. In every iteration, the gradient of the loss function is calculated and the model parameters are updated in the negative gradient direction. The size of the update is governed by the learning rate. A large step can make the process unstable, whereas a small one reduces the convergence rate. A conventional procedure may have difficulty maintaining stable updates on nonlinear functions with complicated landscapes.

The approach discussed in the article replaces direct use of the calculated gradient with a sliding convolution filter. By processing adjacent elements of a value sequence, the filter forms an adjusted estimate of the direction in which parameters should be updated. This operation may suppress isolated sharp variations, but its impact depends on the filter configuration and the problem under consideration. Convolution is not equivalent to simple averaging, because the coefficients determine the contribution of each input.

A neural network interpretation is possible as well. The parameter vector is fed into a gradient calculation block, and its output enters a one-dimensional convolutional layer. The next approximation is then formed. The resulting scheme can be understood as a neural network while keeping the classical gradient method distinct from its modification. Assessing the method requires numerical tests on several functions. The assessment should include accuracy, convergence rate and robustness to changes in step size. Comparisons with ordinary gradient descent should use identical initial conditions, stopping criteria and computing resources. Otherwise, a difference in performance may reflect experimental settings rather than filtering.
