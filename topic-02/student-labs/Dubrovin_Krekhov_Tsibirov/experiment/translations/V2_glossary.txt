PART A
Title: Method of Convolutional Gradient Descent
Abstract: This study proposes improving gradient descent by applying a sliding convolutional filter to gradient values. The method targets objective functions with complex landscapes and includes an interpretation of the computation as a neural network. Numerical experiments described in the article indicate high accuracy and efficiency of the resulting approach.
Keywords: global optimization, objective function, gradient method, nonlinear function, neural network, algorithm.

PART B
Gradient descent is a numerical optimization method for minimizing an objective function. At each iteration, the algorithm evaluates the gradient of a loss function and updates the model parameters in the direction of the negative gradient. The learning rate controls the update size: a step that is too large can cause instability, while a very small step slows convergence. When an objective function is nonlinear and has a complex landscape, the standard algorithm may struggle to maintain a stable sequence of updates.

The proposed modification applies a sliding convolutional filter instead of using the gradient without processing. It combines neighboring elements in a sequence to form an adjusted estimate of the parameter-update direction. The procedure can reduce the effect of isolated sharp variations, but the outcome depends on the filter configuration and the optimization problem. Convolution is not merely averaging: the filter coefficients specify the contribution of each input value.

The computation also admits a neural network interpretation. A vector of model parameters enters the gradient computation block, and the resulting gradient is passed to a one-dimensional convolutional layer before the next approximation is calculated. This representation links the computational steps to a neural network while preserving the distinction between the standard gradient method and the modified algorithm. Evaluation calls for numerical experiments involving several functions. Relevant criteria include solution accuracy, convergence rate, and stability under changes in step size. To compare the modification with classical gradient descent, one should keep the initial conditions, stopping criteria and computational resources constant. Only then can a gain reasonably be associated with the filter instead of differences in the experiment setup.
