# Part A

## Machine Learning Methods for Wildfire Detection

Abstract. This paper presents an analysis of three machine learning algorithms: random forest, logistic regression, and convolutional neural network. A review of scientific and technical literature relevant to the research topic is conducted, and the key advantages and limitations of the algorithms are analyzed. Particular attention is paid to the application of these algorithms to image classification tasks, data collection, and the preprocessing of satellite imagery for model training. The paper includes practical implementations and a comparative analysis of the algorithms' performance under different conditions. The aim of this paper is to provide an understanding of the mathematical foundations of these algorithms and the practical aspects of applying machine learning algorithms to wildfire detection in satellite imagery.

Keywords: logistic regression, random forest, convolutional neural network, satellite imagery, wildfire, spectral bands, confusion matrix, ROC-AUC metric.

# Part B

## Random Forest

The random forest ensemble algorithm was selected for comparison with the previously examined algorithm. Models based on this algorithm showed no signs of overfitting, even when trained on a combination of all spectral bands of the images, achieving an ROC-AUC score of 0.8572. However, the model trained on a combination of spectral bands 2–7 demonstrated better performance, with an ROC-AUC score of 0.8603. The model parameters were as follows: 200 decision trees and standard class weight balancing. For the first model, the maximum decision tree depth was 15, the minimum number of images per leaf node was 2, and the minimum number of images required to split an internal node was 5. For the second model, the maximum decision tree depth was 20, the minimum number of images per leaf node was 5, and the minimum number of images required to split an internal node was 2.

The confusion matrices for the models trained on all seven spectral bands and on six spectral bands excluding the coastal aerosol band are presented in Figs. 3 and 4, respectively.

The confusion matrices (Figs. 3 and 4) demonstrate how poorly the models classify images belonging to class 1 (fire). Two-thirds of such images were incorrectly classified as class 0 (no fire). This classification performance is unacceptable for the task of detecting active fire locations to support rapid firefighting operations. The random forest model trained on all spectral bands provides more accurate predictions for class 1 but also produces more incorrect predictions for class 0. Standard class balancing methods are not suitable for the random forest algorithm in this case.

Evaluation on the test images revealed that neither model detected any fire locations in the images. Training on all available spectral bands did not resolve this issue, while the methods used to address the imbalanced class distribution in logistic regression proved less effective for the random forest algorithm. Based on these results, further consideration of the random forest algorithm as a means of achieving the research objective is not justified.
