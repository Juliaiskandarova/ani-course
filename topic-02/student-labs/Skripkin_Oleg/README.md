# Лабораторная работа №2

Промпты P1/P2, исходные фрагменты, опубликованный английский эталон и PDF статьи находятся в корне архива. В responses/ лежат шесть ответов без правок и шесть протоколов API (JSON). Формулы в исходных файлах и в ответах сохранены в линейной записи для воспроизводимости. В Word использованы редактируемые формулы.

metrics_A.csv содержит BLEU-4 и косинусное сходство TF-IDF. Дополнительный показатель chrF рассчитан скриптом, в таблицу отчёта он не включён. term_scores.csv содержит результаты ручной проверки по отдельным терминам.

Для повторного расчёта метрик установите sacrebleu==2.6.0 и запустите calculate_metrics.py. Скрипт использует сохранённые ответы и работает без ключа API.

Итоговый отчёт: report.pdf. Редактируемая версия: report.docx.
